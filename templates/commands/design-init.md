Use the ui-ux-design-kit skill to set up the design system for this project.

Product and audience: $ARGUMENTS

Do this:
1. Detect the stack and any existing styles or components from the project files.
2. If DESIGN.md already exists, read it and summarize it instead of replacing it.
3. Otherwise create DESIGN.md in the project root with the colors, type, spacing, radius, shadows, app shell and component list, with a visual direction chosen for this product and audience.
4. Add the tokens to the project in its own format (CSS variables, Tailwind config, or theme file).
5. Do not design screens yet. Reply with a short summary of the direction and the next step.
